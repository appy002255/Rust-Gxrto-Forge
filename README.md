# GXTRO Forge (Rust 重構版)

> 個人高中生 Vibe Coding 製作的影片剪輯軟體 — 使用 **Rust** 完全重構，主打輕量、高效預覽與離線 AI 自動字幕。

---

## 核心特色

- **Rust 原生重構**：採用 Rust + `iced` 圖形介面與 `GStreamer` 媒體核心，啟動快、記憶體佔用低。
- **開始選單與多比例畫布**：支援 `16:9` 橫向影片（1920×1080）、`9:16` 直式短影音（1080×1920）與依素材自動調整比例，並可一鍵開啟 `.gxtro` 專案與最近專案。
- **離線 AI 語音字幕**：內建一鍵下載與安裝 **Faster-Whisper-XXL** 引擎與語音模型（支援 GPU 加速），免寫指令即可自動生成時間軸字幕，支援自訂字體（`.ttf` / `.otf`）。
- **硬體加速匯出**：自動偵測可用硬體編碼器並自動命名 `_gxtro` 輸出檔。
- **開機檢查與輕量自動更新**：內建 `GXTRO Updater`，同執行期環境小改版僅下載約 15 MB 輕量更新包，保留所有個人專案、設定與已下載的 AI 模型。

## 下載與安裝

前往本專案的 [Releases 頁面](https://github.com/appy002255/Rust-Gxrto-Forge/releases/latest) 下載最新版本：

### 方式一：安裝版（推薦）
1. 下載 `GXTRO-Forge-Setup-v<版本>-win64.exe`。
2. 執行安裝精靈，依指示完成安裝（預設會建立桌面捷徑，並註冊 `.gxtro` 專案檔雙擊關聯）。

### 方式二：免安裝隨身版
1. 下載 `GXTRO-Forge-v<版本>-portable-win64.zip`。
2. 解壓縮至任意資料夾（專案與設定會直接儲存在同目錄的 `data/` 內，不寫入系統文件夾）。
3. 雙擊 `GXTRO Forge.exe` 即可使用。

> *(註：Release 內的 `patch-win64.zip` 與 `latest.json` 為軟體內建自動更新器專用，一般下載無需手動抓取。)*

## 使用教學

### 1. 建立或開啟專案
啟動程式進入開始選單後，可選擇：
- **16:9 橫向影片**：適合 YouTube、教學與一般橫向剪輯。
- **9:16 直式短影音**：適合 Shorts、Reels、TikTok 直式預覽與匯出。
- **原始比例專案**：進入編輯區後依匯入的第一支素材自動調整解析度。
- **開啟專案檔 (.gxtro)...** 或從右側「最近專案」快速繼續編輯。

### 2. 匯入素材與基本剪輯
1. 點擊左側素材庫匯入影片、音訊或圖片，**雙擊左側素材**或拖曳即可加入時間軸。
2. 將播放頭移至欲裁切處，按 `S` 分割片段；選取片段後按 `Delete` 或 `D` 刪除。
3. 支援軌道切換（`↑` / `↓`）、位置微調（`←` / `→`）、剪下／複製／貼上與復原／重做。
4. 點擊片段可於右側屬性欄調整音量與參數；按 `Ctrl + S` 儲存 `.gxtro` 專案。

### 3. 使用 AI 自動生成字幕
1. **首次使用**：點擊頂部選單 **「編輯 → AI 語音辨識字幕...」**（或按 `Ctrl + Alt + S`），若尚未安裝引擎，依畫面提示點擊「一鍵下載並安裝」（程式會自動從 `Support_Package` 下載並解壓至本地，僅需下載一次）。
2. 安裝完成後即可離線辨識軌道語音並自動產生字幕片段。
3. 如需更換字幕字體，可透過頂部 **「設定 → 匯入自訂字體 (.ttf, .otf)...」** 載入字體檔。

### 4. 偏好設定與自動更新
- 按 `Ctrl + ,` 或點擊 **「設定 → 偏好設定...」** 可調整縮圖、波形、AI VAD 與更新清單設定。
- 點擊頂部 **「說明 → 檢查更新...」** 可手動檢查最新版本，若有新版可直接點擊安裝，系統會自動關閉主程式、套用更新並重新啟動。

### 5. 匯出成品
- 透過頂部選單 **「檔案 → 匯出影片...」** 選擇輸出路徑，軟體會自動為檔名加上 `_gxtro` 後綴並進行編碼輸出。
